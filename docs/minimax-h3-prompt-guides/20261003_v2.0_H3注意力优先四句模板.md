# H3 注意力优先 · 四句模板（v2.0）

> **来源**：用户实测结论 —— H3 注意力差，官方六段式当 prompt 模板用是错的，纯抽卡；关键在注意力分配，不在中英文。
> **整理**：把该判断机制化，补三个缺口，落成可复用模板。
> **标注**：【实测】= 用户观察；【官方】= 文档原文；【推断】= 我的判断，待验证。

---

## 一、为什么四句结构有效（机制）

**① 首句占最大权重 —— 这是所有文本条件模型的通性**

条件信号越靠前，对后续生成的锚定越强。所以第一句不能是铺垫、不能是景别描述，**必须是"这条片子是什么"的总纲**。你把它放第一句，等于用最贵的位置买"全局语义"。

**② 末句回扣 = 首尾夹心（primacy + recency 双端点强化）**

长 prompt 的中段是注意力洼地。只在开头强调一次，权重会随着后续 token 一路衰减；在结尾**再激活一次**，就把同一个语义锚在两个高权重位置各钉了一次。

**③ 六段式的真实问题：它是"人的账本"，不是"模型的注意力结构"**

`retention_analysis`、`overall_soundscape`、`non_diegetic_music` 这三段的作用是**逼人别漏项**。但对"跟随参考视频"这类任务，它们对模型没有正向约束、只消耗注意力预算。

【推断】更关键的是：`attribute_transfer` / `fully_preserved` 这些标记是**给输出格式用的固定枚举**，**没有任何证据表明模型对这些枚举词有特殊响应**。它们被当成 prompt 正文塞进去，就只是稀释。【实测】你的两版失败样本都是六段全上 —— 与这个判断一致。

**结论**：六段不是错，是**被用错位置了**。它应该留在你自己核对用的版本里，不该进给模型的 prompt。

## 二、我要补的三点

### ① 回扣句必须"逐字复用"第一句的关键名词，不能换同义词

这是这套结构能不能起效的关键细节。

- ✅ 第一句 `Reproduce the reference video exactly...` → 第四句 `Reproduce the reference video exactly...`
- ❌ 第一句 `Reproduce the reference video exactly...` → 第四句 `Keep the original footage's motion unchanged...`

换说法激活的是**另一批表征**，不构成"二次强化"，反而在末尾开了一个新话题。**回扣要的是同一串词回来，不是同一个意思换种说法。**

### ② 四句是"分布方式"，不是"可以多写"的许可

真正起作用的是**总信息量低**，四句只是让低信息量分布在高权重位置。

所以必须配一条硬约束：**每句 ≤ 40 词，全篇 ≤ 160 词。**

如果每句写到 80 词，注意力照样散 —— 那只是把六段式的毛病改成了四段式。

❌ 禁止项不要单独成句，也不要超过 1 项。上一轮已经证明：`do not copy performers, costumes, background, lighting, audio, camera` 这种清单会把模型仅有的空间锚和镜头锚一起撤掉。

### ③ 回扣句里不能引入任何新信息

第四句只能**回扣第一句**。一旦塞进新的动作、新的道具、新的场景，它就从"强化"变成"新话题"，反过来分走注意力。

- ✅ `Reproduce the reference video exactly — same choreography, same timing, same camera, same set; only the two performers are replaced.`
- ❌ `Reproduce the reference video exactly, and she smiles at the end while the necklace glints.`

### 关于"不是中英文"这一点

方向同意：**语言不是主因，别在语言上找答案。**

保留一条次要建议：【官方】正文写英文、只在台词（`<d>[中文] ...</d>`）和画内可见文字处保留原语言。理由是中英混排会给 tokenizer 添噪声 —— 但这属于次要因素，**不要为了迁就它去牺牲句子的注意力结构**。

## 三、四句模板

### 通用版

```text
1. 总纲：这条片子是什么（一句说完全局）
2. 谁是谁：每个主体 ↔ 哪份素材（身份锚点，一句绑完）
3. 详细：只写最关键的差异点（≤ 2 句，不写全片剧本）
4. 回扣：逐字复用第 1 句的关键名词 + 一句话说明替换了什么
```

### 填好的实例（你这单：双人舞蹈换人）

```text
Reproduce the reference video exactly with two new performers.
<Subject 1> is the woman from <Picture 1>; <Subject 2> is the man from <Picture 2>.
They perform the same dance in the same hot-pink studio on the same beats, the woman's long braid and gown following the motion of the original bodies.
Reproduce the reference video exactly — same choreography, same timing, same camera, same set; only the two performers are replaced.
```

**约 70 词。** 注意第 4 句的 `Reproduce the reference video exactly` 是**逐字**从第 1 句搬过来的。

### 多素材版（需要绑很多素材时）

```text
1. 总纲
2. 谁是谁（把主体和素材绑成一行一个：A from Picture 1; B from Picture 2; set from Picture 3）
3. 详细
4. 回扣
```

## 四、六段 → 四句 的映射（看清删了什么）

| 六段 | 四句版怎么处理 | 理由 |
|---|---|---|
| `subject_definitions` | **保留** → 第 2 句 | 身份锚点必须有，但要压成一句 |
| `summary` | **保留** → 第 1 句 | 总纲，占注意力最贵的位置 |
| `retention_analysis` | **删掉** | 【推断】枚举标记是输出格式，不是模型约束 |
| `detailed_description` | **大幅压缩** → 第 3 句 | 从 350–500 词压到 ≤ 2 句 |
| `overall_soundscape` | **删掉**（除非要控音效） | 不跟随任务时纯负担 |
| `non_diegetic_music` | **删掉**（除非要控配乐） | 同上 |
| — | **新增** → 第 4 句 | 回扣强化 |

**净效果**：从 ~400 词压到 ~70 词，且锚点从"散布在六段里"变成"钉在首尾两个高权重位置"。

## 五、还没验证的部分（诚实标注）

1. **【推断，未验证】删除 `retention_analysis` 与两个声音段是否真的无害。** 官方文档没有说这些段落对模型有强约束，但也没有说可以省。→ **建议 A/B**：同一素材同一 seed，四句版 vs 六段版各出一次对比。
2. **【推断】"逐字回扣"比"同义回扣"更有效。** 机制上讲得通（激活同一批表征），但没有官方依据。→ 值得单独 A/B 一次。
3. **【实测待补】"每句 ≤ 40 词 / 全篇 ≤ 160 词"这个阈值是我的估计**，不是测出来的。建议以 70 词那版为基准，每次只加一句，观察从第几句开始明显掉。

## 六、验证顺序（一次只改一个变量）

1. **四句版**（上面那 70 词的）先出一版 → 记下它跟参考视频的贴合度
2. 同参数、同素材，出**六段版**做对照 → 确认"话少"是不是真的更跟
3. 若四句版明显更好 → 单独测**逐字回扣 vs 同义回扣**
4. 若都好 → 再测**每句加长 20 词**，找掉点

四步走完，你这套方法就从"经验"变成"有数据的方法"了。
